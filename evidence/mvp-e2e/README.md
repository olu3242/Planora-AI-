# Planora MVP E2E Evidence

This directory records executable evidence for the bounded Agentic OS and execution runtime added to the already-certified deterministic Forecast MVP. It contains no manufactured production evidence and no claim of external-user validation.

The source assertions live in `tests/unit/agent-runtime.test.ts`, `tests/integration/agentic-runtime.test.ts`, `tests/security/authorization.test.ts`, and `tests/e2e/workflow.e2e.ts`.
