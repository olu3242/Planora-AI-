# Planora Pain-Point Matrix

| FP&A pain point | Capability | Evidence of resolution |
|---|---|---|
| Fragmented financial data | Canonical Financial Model | Reconciled facts and metric lineage |
| Spreadsheet dependency | Excel interoperability | Wide/long mapping and controlled round trip |
| Slow budgeting | Driver planning workflow | Approved immutable plan version |
| Static forecasts | Continuous forecast | Published version, movement and new version |
| Difficult variance investigation | Variance Intelligence | Exact decomposition and source drill |
| Slow what-if analysis | Scenario Lab | Shared-engine option comparison |
| Reports without accountability | Decision Hub | Decision, owner, action and audit |
| Numbers are not trusted | Governance/DQ | $0 reconciliation and human certification |
| Manual repetitive analysis | Copilot | Authorized evidence-grounded response |
| Reactive finance | Governed agents | Audited recommendation and approval gate |
| Lost management actions | Outcome tracking | Expected/realized impact and realization |
| Excel migration complexity | Universal mapper | Reusable versioned mapping with drift review |
