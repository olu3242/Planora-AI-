# Planora brand kit — proposed design system

Includes standalone SVG logo and mark, CSS and JSON design tokens, a palette preview, and original SVG interface icons.

## Usage
- `planora-logo.svg`: horizontal lockup for light backgrounds.
- `planora-mark.svg`: favicon/app icon source.
- `tokens.css`: import into the website stylesheet.
- `tokens.json`: map into Tailwind or design tooling.
- `icons/`: 24×24 outlined SVG icons; use CSS `color` or SVG stroke overrides.

All marks are new vector approximations inspired by the landing-page concept, not extracted source vectors from the generated mockup. Review and approve before treating as final brand assets. No external icon font is required.
